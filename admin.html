One Pager 360° · Admin actualización manual de KPIs ← volver al dashboard

1 · Sube los archivos .xlsx o .csv

Sube el/los que quieras actualizar; lo que no subas no se toca. Las columnas se detectan por su encabezado y el país se infiere por cocina. Se ignoran filas Total, CP y Acopio.

Accuracy

Encabezados tipo: scheduled_date, kitchen_id, Promedio de Indicador. Si hay varias fechas usa las 2 más recientes (actual/previa); si hay una sola, solo actual.

GAP Weekly

Cocina/Locación, Week, %FoodCost, %GAP Bono, GAP Oper, %Ajustes, %Mermas, %Bajas, %Frytol, %Rend. Usa 2 semanas (actual/previa).

GAP MTD

Cocina/Locación, Week, %GAP Bono, GAP Oper. Usa la semana más reciente.

2 · Revisa el preview

Verifica cocinas y valores antes de publicar. Las cocinas que no existan en el dashboard se ignoran.

3 · Publicar

Ingresa la clave de admin y publica. Hace commit al repo y Vercel redespliega en ~1 min.

La clave y el token de GitHub viven solo en el servidor (variables de entorno de Vercel); nunca se exponen aquí.
